How to use this screener
  1. Leave Symbols blank for the NSE universe, or enter a focused list for a faster run.
  2. Start with Bullish, Swing Length 5, Wick invalidation, and the 10% target.
  3. Prior Samples, Target Rate, and Average Return show how the same stock and side behaved before the current signal.

The Pine alert is confirmed one bar after the wick retest, so the backtest enters at the following session's open. Daily candle-direction volume is used because lower-timeframe volume is not present in the stored OHLCV.
